# Projet Web PHP/MySQL

Application web PHP avec gestion de base de données MySQL.

## Description

Application web développée en PHP suivant une architecture MVC. Elle inclut une gestion complète de base de données via MySQL et une interface utilisateur accessible depuis un navigateur.

## Fonctionnalités

- Architecture MVC en PHP
- Gestion de base de données MySQL
- Interface web complète
- Déploiement possible en local (XAMPP) ou en ligne (AlwaysData)

## Technologies

- PHP
- MySQL
- HTML / CSS
- XAMPP

## Installation et lancement

**En local :**
```bash
# 1. Importer la base de données
# Aller sur phpMyAdmin et importer le fichier : creationtable.sql

# 2. Placer le projet dans XAMPP
# Copier le dossier dans : xamp/htdocs/NomDuFichier

# 3. Lancer depuis un navigateur
# Ouvrir : http://localhost/NomDuFichier/Accueil.php
```

**En ligne :**
Les identifiants de connexion à la base de données AlwaysData sont disponibles dans `../conf/projet.ini`.
